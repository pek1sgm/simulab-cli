## 3. Conclusion

According to the current procedure on model exchange, which is described in AS Methods Library, models created by VM/ENC4 have to be approved and forwarded to customer by client (e.g., SYS-PL). If these models cannot be approved, an iteration loop involving VM/ENC4 is necessary.

VM/ENC4 will support client if she/he is not sure whether SiL models can be approved or not and for transferring the model to the final customer/OEM.

> **Good to know:** SiL models enable Bosch AS to do further investigations (see attachment 3.3) either on steering system or on vehicle level. Several investigations require input data representing the dynamic behaviour of vehicle components (e.g., vehicle axis). Those input data could be provided by AS/ENS. Kindly come up to the corresponding department for further information.
